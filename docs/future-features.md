# Future Features

These features are explicitly excluded from MVP.

## Excluded From MVP

- Customer management
- Appointment booking
- Loyalty program
- Membership
- Product inventory
- GST
- Billing printer
- WhatsApp marketing
- Online booking
- Multi-branch support
- Salary management
- Attendance

## Evaluation Principles

A future feature should be considered only if:

- It does not slow down daily income and expense entry.
- It fits the digital notebook positioning.
- It can work offline or degrade gracefully.
- It has clear value for small salons.
- It does not turn the product into ERP software.

## Possible Future Sequencing

### Version 1.1

- Export reports
- Simple data correction history
- Additional languages (Telugu, Punjabi, Malayalam, Odia)
- Optional service categories

### Version 1.2

- Customer names as optional notes, not full CRM
- Basic appointment reminders if demand is proven
- Advanced report filters

### Version 2.0

- Multi-device owner access
- Employee login with restricted permissions
- Multi-branch only if product-market fit requires it

## Guardrails

- Do not introduce customer management as a hidden dependency for income entry.
- Do not require internet for future workflows.
- Do not add complex accounting terms to primary UI.
- Do not make setup longer for first-time users.
