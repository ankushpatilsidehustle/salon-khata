# Personas

## Primary Persona: Owner-Operator Barber

- Runs a 1 to 3 chair shop.
- Handles services, cash, UPI payments, and daily totals personally.
- Uses a notebook or memory for staff commission.
- Has limited patience for setup, typing, or complex reports.
- Needs the app to work during network drops.

### Jobs To Be Done

- Record a haircut or shave quickly while serving customers.
- See today's collection at a glance.
- Know how much commission each employee earned.
- Avoid mistakes at closing time.

## Primary Persona: Beauty Parlour Owner

- Runs a small parlour with 2 to 8 employees.
- Offers multiple services with different prices.
- Pays employees different commissions for different services.
- Wants clean records without hiring an accountant.

### Jobs To Be Done

- Record multi-service visits quickly.
- Track employee commission accurately.
- Check daily and monthly performance.
- Keep expense notes organized.

## Secondary Persona: Family Member Helper

- Helps the owner occasionally.
- May not know all services or prices.
- Needs simple choices instead of typing.

### Jobs To Be Done

- Select employee and service from obvious lists.
- Save records without understanding backend concepts.
- Avoid accidental deletion or wrong entries.

## Device And Context Assumptions

- Mostly Android phones.
- Some older devices with limited storage and memory.
- Mixed indoor/outdoor lighting.
- One-handed usage is common.
- Network can be slow or unavailable.
- Users may switch between English and Indian languages in future releases.

## UX Implications

- Large tap targets are mandatory.
- Lists should prioritize recent and active items.
- Forms should avoid typing when selection is possible.
- Empty states must guide action without sounding technical.
- Sync errors should not block daily work.
